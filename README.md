# 🏦 Sistema de Préstamos — Frontend

Interfaz web desarrollada con React para el Sistema de Préstamos.

## Tecnologías
- React 18
- React Router DOM
- Axios
- CSS Modules

## Módulos
- ✅ Login con JWT
- ✅ Clientes
- ✅ Préstamos con tabla de amortización
- ✅ Pagos
- ✅ Bitácora
- ✅ Reportes por rango de fechas
- ✅ Exportar a PDF y Excel

## Instalación

### Requisitos
- Node.js 18+

### Configuración
1. Instalar dependencias:
```bash
npm install
```

2. Ejecutar:
```bash
npm start
```

3. Abrir en navegador: http://localhost:3000
